Protecting Wildlife, Protecting People

EcoSentinel is an AI-powered smart wildlife surveillance and alert network designed to detect wild animals encroaching near human settlements and instantly alert forest authorities to prevent human-wildlife conflict.

The Problem

Human-wildlife conflict causes thousands of injuries, deaths, and crop losses every year in forest-border communities worldwide.

Our Solution

AI-powered camera surveillance that detects animals in real-time and immediately alerts forest officers via SMS and dashboard notifications.

The Impact

Faster response times, reduced human casualties, improved wildlife conservation, and data-driven forest management decisions.

Technology Stack

Python 3.14
Backend language for AI processing and server logic
Django 6.0
MVC web framework with REST APIs and admin panel
YOLOv8 (Simulated)
Real-time object detection model for wildlife species
OpenCV
Image processing, bounding box annotation, frame analysis
Bootstrap 5
Responsive UI framework with dark eco-green theme
Leaflet.js
Interactive map with real-time GPS markers and popups
Chart.js
Analytics charts for detection trends and species distribution
SQLite
Embedded database for local demo — scalable to PostgreSQL

System Workflow

1
Camera Feed Monitoring

Forest border cameras upload images/video. Users can also manually upload camera feeds through the Live Detection page.

2
AI Animal Detection

OpenCV + YOLOv8 model analyzes frames and identifies wildlife species with bounding boxes and confidence scores.

3
GPS Location Capture

Browser geolocation API or camera GPS data provides precise coordinates. Displayed on Leaflet.js interactive map.

4
Alert Generation

Detection stored in SQLite database. Alert dashboard updated. SMS notification simulated via Twilio/Fast2SMS API.

5
Officer Response

Forest officers receive alerts on their dashboard, view detection images, track locations on the map, and update action status.
